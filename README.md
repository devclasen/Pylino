# Pylino

Ein sehr einfacher Python-Editor – komplett im Browser, ohne Installation.

**Direkt starten:** https://devclasen.github.io/Pylino/

- **Computer:** Python läuft im Browser (Pyodide).
- **Pico:** MicroPython auf dem Raspberry Pi Pico über USB (Web Serial).

Unterstützt werden aktuelle Versionen von Chrome und Edge.

Programme bleiben ausschließlich im Browser – es gibt keinen Server, keine Accounts und kein Tracking.
