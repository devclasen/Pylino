 Hilfe zu Pylino

  

    
Was brauche ich?

    
    
      
  • Einen aktuellen Chrome oder Edge. Firefox und Safari können nicht mit dem Pico sprechen.
    • 
      
  • Beim Öffnen eine Internetverbindung, weil Python (ca. 10 MB) nachgeladen wird. Danach ist es im Browser zwischengespeichert.
    • 
    


    
Python auf dem Computer

    
Oben Computer wählen und Ausführen klicken. Wenn dein Programm input() aufruft, leuchtet unten das Eingabefeld auf. Fast die ganze Standardbibliothek funktioniert, z. B. math, random, time, datetime, json, statistics.


    
Was Pylino kann – und was nicht

    
Pylino ist ein kleines Python für den Einstieg. Damit geht:

    
    
      
  • alle Grundlagen: Variablen, Rechnen, if, Schleifen, Funktionen, Listen, Dictionaries
    • 
      
  • Ein- und Ausgabe mit input() und print()
    • 
      
  • die Standardbibliothek, z. B. math, random, time, datetime, statistics, json
    • 
      
  • auf dem Pico: LEDs, Taster, Sensoren, PWM und alles aus machine
    • 
    

    
Das kann Pylino (noch) nicht:

    
    
      
  • Programme mit eigenen Fenstern, Spiele oder Turtle-Grafik (tkinter, turtle, pygame)
    • 
      
  • Dateien auf deinem Computer lesen oder schreiben – mit open() erstellte Dateien verschwinden beim Neuladen
    • 
      
  • Maus und Tastatur steuern, andere Programme starten, mehrere Abläufe gleichzeitig (Threads)
    • 
      
  • Verbindungen ins Internet
    • 
    

    
Wenn dein Programm so etwas versucht, sagt dir Pylino Bescheid.


    
Pico vorbereiten (einmalig)

    
    
      
  1. Den Knopf BOOTSEL auf dem Pico gedrückt halten und das USB-Kabel einstecken.
    2. 
      
  2. Ein Laufwerk namens RPI-RP2 (beim Pico 2: RP2350) erscheint.
    3. 
      
  3. Auf micropython.org die passende .uf2-Datei laden (Pico, Pico W, Pico 2 …) und auf das Laufwerk ziehen.
    4. 
      
  4. Der Pico startet neu – fertig.
    5. 
    


    
Mit dem Pico arbeiten

    
    
      
  1. Oben Pico wählen, dann Pico verbinden und im Fenster den Pico auswählen.
    2. 
      
  2. Ausführen startet das Programm auf dem Pico. Stopp beendet es.
    3. 
      
  3. Auf Pico speichern legt das Programm als main.py ab. Es startet dann jedes Mal automatisch, wenn der Pico Strom bekommt.
    4. 
      
  4. Ins Eingabefeld kannst du auch direkt Befehle für den Pico tippen, z. B. print(1+1).
    5. 
    


    
Wenn etwas nicht klappt

    
    
      
  • Pico erscheint nicht in der Liste: Ist MicroPython drauf? Anderes USB-Kabel probieren – manche Kabel laden nur.
    • 
      
  • „Port wird bereits verwendet“: Ist Thonny oder ein zweiter Tab mit Pylino offen? Schließen und neu verbinden.
    • 
      
  • Programm hängt: Stopp drücken. Auf dem Computer wird Python dabei kurz neu gestartet.
    •
